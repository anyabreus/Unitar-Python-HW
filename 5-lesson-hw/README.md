# Renovation Calculator

Консольна програма для розрахунку орієнтовної вартості ремонту квартири на основі даних із CSV-файлу.

## Можливості

- Розрахунок загальної вартості ремонту.
- Окремий розрахунок вартості робіт і матеріалів.
- Розрахунок середньої вартості ремонту за 1 м².
- Визначення трьох найдорожчих позицій.
- Перевірка коректності даних у CSV-файлі.
- Пропуск некоректних рядків із формуванням попереджень.
- Обробка помилок читання файлу та некоректних значень.

## Вхідні дані

Дані для розрахунку зберігаються у файлі `data/renovation.csv`.

Формат CSV:

| Поле       | Опис                            |
| ---------- | ------------------------------- |
| `category` | Категорія: Роботи або Матеріали |
| `name`     | Назва роботи або матеріалу      |
| `quantity` | Кількість                       |
| `unit`     | Одиниця виміру                  |
| `price`    | Ціна за одиницю                 |

Некоректні рядки пропускаються та додаються до списку попереджень.

## Запуск програми

**Вимоги:** Python 3.10 або новіша версія.

1. Клонуйте або завантажте репозиторій.
2. Перейдіть у кореневу директорію проєкту.
3. Запустіть програму:

```bash
python main.py
```

## Конфігурація

Основні налаштування програми знаходяться у `app/config.py`:

- `APARTMENT_SIZE` — площа квартири в м².
- `CATEGORIES` — перелік допустимих категорій.
- `DATA_FILE` — шлях до CSV-файлу з вхідними даними.

## Обробка помилок

Програма передбачає обробку таких ситуацій:

- відсутність CSV-файлу;
- відсутність доступу до файлу;
- відсутні або некоректні значення в рядках;
- некоректна категорія;
- недопустимі значення кількості або ціни;
- ділення на нуль під час розрахунку вартості за м².

Для помилок, пов'язаних із даними, використовуються власні класи винятків.
