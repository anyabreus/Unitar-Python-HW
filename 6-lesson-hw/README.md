# Калькулятор ремонту

Застосунок для власників квартири та тих, хто планує ремонт, і допомагає дізнатися орієнтовну вартість ремонту на основі витрат і метражу.

Онлайн-версія: https://renovation-calculator.streamlit.app/

## Як запустити

Потрібні Python 3.10 або новіша версія.

1. Перейдіть у папку проєкту.
2. Встановіть залежності:

```bash
python -m pip install -r requirements.txt
```

3. Запустіть застосунок:

```bash
streamlit run streamlit_app.py
```
